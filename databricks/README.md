# Azure Databricks — Interview Prep Repo

A structured, beginner-to-advanced knowledge base for Azure Databricks interviews and real-world scenario prep. Each topic folder contains three files:

- **`concepts.md`** — theory, architecture, and how it actually works
- **`interview-qna.md`** — commonly asked interview questions with detailed answers
- **`scenarios.md`** — "how would you design / debug / optimize this" real-world case studies

Topics are added two at a time, in curriculum order. Check off items below as they're completed.

## How to use this repo

1. Work through topics top to bottom — later topics assume earlier ones.
2. Read `concepts.md` first, then test yourself against `interview-qna.md` without peeking, then work through `scenarios.md` out loud as if in a live interview.
3. Revisit the **Advanced** and **System Design** sections closer to interview day — that's where senior/lead-level questions concentrate.
