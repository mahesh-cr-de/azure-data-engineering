# azure-data-engineering

Data engineering patterns and pipelines on Azure — Databricks, Data Factory, Delta Lake, and interview prep, organized by topic.

## 📂 Contents

| Folder | What's inside |
|---|---|
| [data-factory/](data-factory/) | Interview-ready ADF notes — fundamentals, core ETL/ELT scenarios (incremental load, watermark CDC, metadata-driven pipelines), and data transformation (Mapping/Wrangling Data Flows, schema drift, SCD) |
| [databricks/](databricks/) | Beginner-to-advanced Databricks knowledge base — architecture, Delta Lake fundamentals, clusters & compute, notebooks/Repos/CLI, data ingestion, and Spark Core |
| [delta-lake/](delta-lake/) | Hands-on SQL/PySpark scripts covering Delta Lake from the basics through performance tuning, UniForm, Change Data Feed, and internals |
| [interview-prep/](interview-prep/) | Azure and agentic AI interview questions with full answers, talking points, and diagrams |

## How to use this repo

Each top-level folder is self-contained with its own `README.md` module index — start there to see the learning path and progress for that topic.
